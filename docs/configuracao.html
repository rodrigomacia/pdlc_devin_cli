Configuração Devin CLI

Estrutura do projeto, permissões, MCP e templates que as skills leem em runtime.

Estrutura do repositório

.
├── AGENTS.md                 # Regras sempre ativas para o agente
├── .devin/
│   ├── config.json           # Permissões do projeto (commitar)
│   ├── config.local.json     # MCP e segredos (NÃO commitar)
│   ├── skills/               # 46 skills (/comando)
│   └── agents/               # 32 perfis de subagentes
├── colmeia/                  # Contratos: fluxos, gates, modelos
│   ├── 00-nucleo … 05-operacao/
│   └── _config/              # Templates de integração
├── docs/                     # GitHub Pages (esta documentação)
└── scripts/
    ├── setup-devin-cli.sh    # Setup inicial
    └── build-docs-site.sh    # Build do site

Script de setup

./scripts/setup-devin-cli.sh           # setup padrão
./scripts/setup-devin-cli.sh --with-docs  # + espelho colmeia em docs/

O script valida skills/agentes, cria _iniciativas/, _handoffs/, _grill/ e gera config.local.json a partir do exemplo.

Arquivos de configuração

ArquivoPropósito
.devin/config.json Permissões de leitura/escrita em colmeia/; versionado no git.
.devin/config.local.json Servidores MCP (OKR, VOC, CI/CD). Copie de config.local.json.example.
colmeia/_config/okr-plataforma.md Skills favo 01 — sync e desdobramento OKR.
colmeia/_config/discovery-tools.md Skills favo 02 — VOC, analytics, Figma, personas sintéticas.
colmeia/_config/construcao-monorepo.md Skills favo 04 — monorepo, CI segregado, CD sandbox/homolog/prod.
colmeia/_config/governanca.md Opcional — checklist /governanca-check.

Exemplo MCP (config.local.json)

{
  "mcpServers": {
    "okr-plataforma": {
      "command": "npx",
      "args": ["-y", "@sua-org/mcp-okr"],
      "env": { "OKR_API_KEY": "..." }
    },
    "ci-cd": {
      "url": "https://mcp.pipeline.example/mcp",
      "transport": "http"
    }
  }
}

Permissões recomendadas

O config.json do projeto libera leitura ampla e escrita em colmeia/. Comandos de shell (Exec) ficam em modo ask — o operador aprova por iniciativa.

Para CI/CD e implementação, adicione em config.local.json: "allow": ["Exec(git)", "Exec(npm)", "Exec(go)"]

GitHub Pages

  1. Build local (opcional) 
    ./scripts/build-docs-site.sh
  2. Push para main — o workflow .github/workflows/pages.yml publica automaticamente.
  3. Ativar Pages (primeira vez): Settings → Pages → Source: GitHub Actions.
