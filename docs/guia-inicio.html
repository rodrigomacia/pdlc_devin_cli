Início / Guia de início

Guia de início rápido

Do zero à primeira iniciativa — Devin CLI como orquestrador multi-agente do ciclo completo.

Pré-requisitos

  • Devin CLI — cli.devin.ai
  • Clone do repositório
  • MCP: OKR, VOC, analytics (ver configuração)
  • ID de iniciativa (ex. conta-digital-q3-2026)

Passo a passo

  1. Execute o setup
    git clone https://github.com/rodrigomacia/pdlc_devin_cli.git
cd pdlc_devin_cli
chmod +x scripts/*.sh
./scripts/setup-devin-cli.sh
  2. Configure integrações
    Preencha colmeia/_config/ e .devin/config.local.json. Detalhes →
  3. Abra o Devin 
    devin
  4. Orquestre 
    /orquestrar-producao conta-digital-q3-2026
  5. Siga o ciclo — forneça dados em [FORNECER]; use /grill-me antes de cada portão.
  6. Handoffs 
    /curar-contexto 01 02 {id}
/curar-contexto 02 03 {id}
