Guia de início rápido

Do zero à primeira iniciativa em produção digital — usando o Devin CLI como orquestrador multi-agente.

Pré-requisitos

  • Devin CLI instalado — cli.devin.ai
  • Clone deste repositório na máquina do Head ou do time
  • Acesso à Plataforma OKR, analytics e VOC (configurados via MCP)
  • Um ID de iniciativa (ex.: conta-digital-q3-2026)

Passo a passo

  1. Execute o setup
    Na raiz do repositório: 
    chmod +x scripts/setup-devin-cli.sh scripts/build-docs-site.sh
./scripts/setup-devin-cli.sh
    Isso cria pastas de runtime, config.local.json e valida skills/agentes.
  2. Configure integrações
    Preencha os templates em colmeia/_config/ e os servidores MCP em .devin/config.local.json. Detalhes em Configuração.
  3. Abra o Devin na pasta do projeto 
    cd /caminho/para/ciclo-de-producao
devin
  4. Orquestre a iniciativa
    Primeiro comando — substitua pelo ID real: 
    /orquestrar-producao conta-digital-q3-2026
    O agente indica o favo atual, artefatos faltantes e a próxima skill.
  5. Siga o ciclo favo a favo
    Forneça dados reais quando aparecer [FORNECER]. Após cada entrega importante, use /grill-me {id} {momento} antes de aprovar o portão.
  6. Handoffs entre etapas 
    /curar-contexto 01 02 conta-digital-q3-2026
/curar-contexto 02 03 conta-digital-q3-2026
# ... conforme decisão do favo 03

Fluxo resumido por favo

FavoO que o Head fazComandos principais
01 Define diretriz e valida OKRs /draft-okr · /desdobrar-okr · /auditar-okr
02 Conduz discovery ponta a ponta /visao-mercado · /visao-produto · /visao-cliente · /feature-stories
03 Testa com clientes reais /design-experimento · /decidir-experimento
04 Aprova spec e valida canário /spec-funcional · /review-pr · /validar-rollout-head
05 Revisa métricas e prioriza insights /review-metricas · /insight-para-discovery

Regras de ouro

  • Simulação ≠ cliente real — SVM (favo 02) não substitui experimentação (favo 03).
  • Review antes de deploy — /review-pr vem antes de CI/CD (favo 04).
  • Scale só com evidência — construção em escala exige validacao_real: confirmada.
  • Head decide — IA propõe; portões são humanos.

Onde ficam os artefatos

colmeia/{favo}/_iniciativas/{id}/   ← saídas das skills
colmeia/_handoffs/                  ← pacotes entre favos
colmeia/_grill/{id}/                ← interrogatórios grill-me

Pastas de runtime são gitignored — não versionam dados de produto.
