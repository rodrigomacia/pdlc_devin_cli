Hierarquia de execução

Como skills, agentes e subagentes se relacionam no Devin CLI (um nível de subagente).

Skill

  • Comando invocável: /nome {args}
  • Define entrada, saída e path em colmeia/
  • Pode rodar inline ou spawnar subagente
  • 14 skills no framework

Agente (AGENT.md)

  • Perfil com system prompt + tools permitidas
  • 9 agentes em .devin/agents/
  • Dono de um favo ou função transversal

Subagente (⊂)

  • subagent: true ou agent: {id} no SKILL.md
  • Contexto isolado; pai sintetiza resultado
  • Não aninha outro subagente
  • Ex.: auditor-okr, reviewer, decidir-experimento

Capacidade (tool)

  • Integração externa ou tool nativa
  • Declarada em allowed-tools + MCP
  • Requisito por etapa — tabela abaixo

Etapas — skills, agentes e modelo de capacidades
